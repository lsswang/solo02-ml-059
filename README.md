# Relational graph comparison and multiview annotation

Python3.11 CPU; install requirements and run `python demo.py`.
This starter provides real ordinary linear transportation and independent
maximum-affinity bipartite identity matches. It does not implement quadratic
relational graph transport or jointly consistent identities across all graphs.
Fixtures are synthetic. No pretrained model, raw image or external data download
is needed. Public POT sources are investigated internally but not copied here.
